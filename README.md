# 🌡️ Confortímetro — Modelo 3D

Modelagem 3D (SolidWorks) do projeto do **confortímetro** — desenvolvimento de 2020.

| Arquivo | Descrição |
|---|---|
| `confortim_Solid.SLDPRT` | Modelo paramétrico da peça/conjunto |

## 🖨️ Como usar

Abra o `.SLDPRT` no SolidWorks (2017 SP3 ou mais novo) para editar. Exporte para `.STL` caso
queira imprimir em 3D.
